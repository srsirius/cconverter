# Конвертер валют с кэшем

Простое консольное приложение на Python, которое конвертирует деньги из базовой валюты в целевую. Программа использует API FloatRates для получения курсов и реализует механизм кэширования для ускорения повторных конвертаций.

## Возможности

*   **Конвертация валют:** Переводит сумму из указанной базовой валюты в целевую.
*   **Механизм кэширования:** Реализует простой кэш для хранения курсов.
    *   При самой первой конвертации программа автоматически загружает в кэш курсы для **USD** и **EUR** (самые популярные валюты).
    *   При последующих запросах она проверяет, есть ли курс в кэше.
    *   Если курс есть в кэше, выводится сообщение: `Oh! It is in the cache!`.
    *   Если нет, программа берет курс из скачанных данных, выводит сообщение: `Sorry, but it is not in the cache!` и сохраняет курс в кэш для будущего использования.
*   **Источник данных:** Использует API `floatrates.com`.
*   **Интерактивный цикл:** Непрерывно запрашивает новую целевую валюту и сумму, пока программу не остановят.

## Алгоритм работы

1.  **Ввод базовой валюты:** Пользователь вводит валюту, которая у него есть (например, `aud`). Она используется для скачивания JSON-файла со всеми курсами.
2.  **Загрузка данных:** Программа скачивает JSON-файл по адресу `http://www.floatrates.com/daily/{base_currency}.json`. Эти данные скачиваются **только один раз** при старте.
3.  **Первичное заполнение кэша:** Программа проверяет, пуст ли кэш. Если да, она заранее заполняет его курсами для `usd` и `eur` из скачанных данных.
4.  **Ввод цели и суммы:** Пользователь вводит валюту, которую хочет получить, и сумму.
5.  **Проверка кэша:**
    *   Если целевая валюта есть в кэше, программа использует этот курс.
    *   Если нет, программа берет курс из изначально скачанного `data`, выводит сообщение о промахе кэша и добавляет этот новый курс в кэш.
6.  **Расчет и вывод:** Программа вычисляет результат и выводит его на экран.
7.  **Повтор:** Программа возвращается к шагу 4 для обработки следующей конвертации.
8.  **Проверка** на правильность ввода отсутствует.

## Технологии

*   **Язык:** Python 3
*   **Библиотеки:**
    *   `requests`: для HTTP-запросов к API.
    *   `json`: для парсинга ответа API.

## Как запустить

1.  Убедитесь, что у вас установлен Python.
2.  Установите библиотеку `requests`:
    ```bash
    pip install requests
    ```
3.  Сохраните код в файл с именем `currency_converter.py`.
4.  Запустите скрипт из терминала:
    ```bash
    python currency_converter.py
    ```
